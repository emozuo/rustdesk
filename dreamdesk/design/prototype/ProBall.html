③ 选了被控端鼠标：锁定时

照 UU「使用被控端鼠标」：本机指针锁在窗口里、藏起来，画面上画出被控端的指针（位置由被控端报回来，所以带加速、程序自己挪指针都不会偏；比本机指针多一个网络来回的延迟）；被控端程序把指针藏了（三维软件拖动旋转时）就不画，松手后再出现。通用模式和专业模式一样。球和菜单收起来，弹一条提示「按 Ctrl+Alt 退出被控端鼠标」。按 Ctrl+Alt 放开后，球回来、本机指针放出来；要再锁，点一下画面（专业窗口是全屏的，指针一直在窗口里，所以不能像通用窗口那样「指针重新进入窗口就再锁」）。

④ 逐项对照

「保留」= 和通用模式效果一样；「去掉」= 在专业模式下没有意义（理由是对着代码核实的）；「专业独有」= 只在专业模式有。 「要新动作」= 专业窗口和会话进程之间要加一条消息（现在悬浮球只有切屏、Ctrl+Alt+Del、锁屏、质量监测、麦克风、HDR、切换通用模式、改分辨率这几条）。

通用控制中心的组项专业模式理由 / 怎么做
显示屏 N显示屏 N 的名称（型号）保留专业窗口里同名同样子。现有的「显示屏 N」文字只有序号，型号要会话进程在专业窗口打开时多传一个字段（新数据）
分辨率：跟随当前显示屏 / 跟随被控端 / 其他分辨率保留效果和通用一样；现在就能用——现有悬浮球「分辨率」子菜单里的原始 / 适应本机 / 支持列表就是这三样，换位置、换叫法；「其他分辨率」是第三级，ball.rs 要支持三级菜单
连接时铺满我所有显示器保留要新动作：会话选项「将我的所有显示器用于远程会话」按机器记，专业窗口读写它；出现条件同通用（本机两块屏以上、对方支持多屏）
切换下一个屏幕保留现有「切换显示器」动作，改成循环下一块；这个窗口固定看某块屏（铺满所有显示器时）灰掉——现有的 display_fixed 逻辑
画质画质档位（画质优先 / 均衡 / 速度优先 / 自定义）、帧率、色彩（真彩 / 常规）去掉专业画面是独立的编码通道，固定 4:4:4、60 帧、30 Mbps（video.rs 的 FPS、BITRATE_KBPS 常量），不读 RustDesk 的画质 / 帧率 / 色彩选项，选了不起作用
HDR专业独有保留现有动作；放在原来「画质」的位置，一级的多选项（对勾，10-27 用户定：不再套一层「画质」）。不支持时灰掉并写原因
窗口显示方式（原始大小 / 适应窗口 / 自定义缩放）、滚动方式、贴边宽度去掉专业窗口一定是全屏铺在一块本机屏上、画面按比例适应（view.rs 的 refit），没有这几种方式，也没有滚动，不读 RustDesk 的显示方式选项
声音静音保留会话选项 disable-audio；声音由会话进程播放，专业模式下照常来。要新动作 + 打开时带初值
麦克风保留（位置不同）通用模式的麦克风是标题栏按钮，专业窗口没有标题栏，放进「声音」子菜单；现有动作
安全锁定远程电脑保留现有动作
禁止对方本地操作保留会话选项 block-input；只有 Windows 被控端且有键鼠权限才出现（同通用）。要新动作
断开后锁定远程电脑保留会话选项 lock-after-session-end；要新动作 + 初值
外设鼠标模式：使用主控端鼠标 / 使用被控端鼠标（10-28 照 UU 改名，被控端鼠标要画出被控端指针）保留（用户定）共用 dd-mouse-mode 这个按机器记的值；要新做：专业窗口的指针锁定（Wayland pointer-constraints + relative-pointer），见下面「鼠标模式」
同步剪贴板、允许复制粘贴文件保留（待实测）菜单项只是读写选项（disable-clipboard、enable-file-copy-paste），同步本身在会话进程里做、不看哪个窗口。风险：Wayland 下写本机剪贴板要有焦点，专业模式下焦点在专业窗口进程里，是否可用没验证过，要实测；不行就两项一起去掉
反转鼠标滚轮、交换鼠标左右键保留Session::send_mouse 已经按这两个选项处理（专业窗口的鼠标事件走同一个函数），现在就生效；菜单项只要读写选项，要新动作 + 初值
工具文件传输、终端保留新窗口由会话进程里的 Flutter 开：专业窗口发动作 → 会话进程推一个事件 → Dart 调 connect()。要新动作 + model.dart 一行事件入口
开始录屏去掉录的是通用画面的帧（客户端侧录制），专业会话期间这块屏没有通用画面，录出来是空的
截图去掉截图是被控端的通用画面服务截的，专业会话期间被控端不给这条连接开这块屏的通用画面（holds_display），截不到
更多发送 Ctrl+Alt+Del保留现有动作
刷新画面去掉它请求通用画面的关键帧，专业画面丢包时自己请求关键帧，这个按钮对专业画面不起作用
重启远程电脑保留（确认方式不同）通用模式点了弹确认框（Flutter 对话框），专业模式下通用窗口藏着、看不见，改成第三级菜单里点「确认重启」。要新动作
显示质量监测保留现有动作；已经读写同一个 show-quality-monitor 选项
切换到通用模式专业独有对应通用模式「更多」里的「切换到专业模式」，现有动作
全屏 / 退出全屏去掉专业窗口本来就是全屏
退出远控保留现有（关专业窗口就结束这次远程）
