# 界面图标清单（10-27）

原型（`prototype/`）里的图标全部用图标库原图，SVG 路径一字不改；改程序里的图标（`flutter/lib/desktop/widgets/dd_icons.dart`）时照这份换。

| 库 | 版本 | 许可 | 地址 |
|---|---|---|---|
| Lucide | lucide-static 0.460.0 | ISC | `https://cdn.jsdelivr.net/npm/lucide-static@0.460.0/icons/<名>.svg` |
| Fluent UI System Icons | @fluentui/svg-icons 1.1.292 | MIT | `https://cdn.jsdelivr.net/npm/@fluentui/svg-icons@1.1.292/icons/<名>.svg` |
| Font Awesome Free（品牌图标） | @fortawesome/fontawesome-free 6.6.0 | CC BY 4.0（要注明出处） | `https://cdn.jsdelivr.net/npm/@fortawesome/fontawesome-free@6.6.0/svgs/brands/<名>.svg` |
| Material Symbols（outlined） | @material-symbols/svg-400 0.23.0 | Apache 2.0 | `https://cdn.jsdelivr.net/npm/@material-symbols/svg-400@0.23.0/outlined/<名>.svg` |

程序里的图标文件由脚本从原文件生成、不手改，原文件（只放程序用到的）和各库的许可原文在 `dreamdesk/design/icons/`：
- Flutter 界面：`python -I dreamdesk/scripts/gen-dd-icons.py` → `flutter/lib/desktop/widgets/dd_icons.dart`
- 专业窗口悬浮球（Rust，tiny-skia 画）：`python -I dreamdesk/scripts/gen-ball-icons.py` → `src/ddpro/ball_icons.rs`（SVG 换算成直线和
  三次曲线；`check-ball-icons.py` 生成原图和换算结果的对照页、截图后逐像素比）

要加图标：照上表地址下载原文件放进 icons 目录，在脚本的表里加一行，重新生成。

用法约定：
- Lucide 是描边图标，线宽统一 1.5（Lucide 支持调线宽，路径不动），常用 16 / 18 / 20 像素。
- Fluent 是填色图标，按显示尺寸用对应号的原图（16 像素用 16 号、20 像素用 20 号），不缩放。
- 窗口按钮的 Lucide 图标在 16 像素下线宽 1 像素、正落在两行 / 两列像素中间，100% 缩放下会发灰：整体右下挪 0.5 像素（只挪位置，不改路径）。

## 设备背景（预置壁纸，10-27 用户：先按最简单的预置）

程序里在 `flutter/assets/dd/`（原型里在 `prototype/wallpapers/`），宽 1280 的 JPEG。仓库的 `.gitignore` 有 `*jpg`，提交要 `git add -f`。

| 被控端系统 | 图 | 来源 / 许可 |
|---|---|---|
| Windows | `wallpaper_windows.jpg` | Windows 11 默认壁纸 Bloom（`C:\Windows\Web\Wallpaper\Windows\img0.jpg` 缩小）。版权归微软，不能随软件分发；用户知情，公司内部先这样用 |
| Linux | `wallpaper_linux.jpg` | Ubuntu 默认壁纸 `warty-final-ubuntu.png`（ubuntu-wallpapers 包，Copyright Ubuntu community contributors，CC-BY-SA-3.0，https://launchpad.net/ubuntu-wallpapers）缩小 |
| macOS / 离线 | 程序里画的渐变 / 灰 | macOS 官方壁纸没有公开原图 |

以后要换成被控端的真实壁纸（UU 的做法：第一次连上时取被控端壁纸、存本机，之后不再更新），方案见 10-27 讨论（做法 D）。

## 程序里和上表还不一样的（10-27 第一版界面）

- 控制中心子菜单右边的箭头：Flutter 3.24 的子菜单按钮把 Material 的实心三角写死在里面，换成 chevron-right 得自己重写子菜单，
  这一版只把它调成次要文字的灰色。
