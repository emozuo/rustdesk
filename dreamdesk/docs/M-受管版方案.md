# 受管版方案（M 系列，2026-10-26）

企业专用产品，只出受管版。服务端协议、网关设计在 dreamdesk-gateway 仓库（`docs/协议-连接票与设备签名.md`、`docs/S1-方案.md`）；
kiosk 瘦客户机另见 [K-kiosk方案.md](K-kiosk方案.md)。

## 用户已定（10-26）

- **只出受管版**。不受管的版本只留给开发测试。正式受管版要密钥仪式填好产品钥才编得出来。
- **所有客户端都必须登录账号**，从网关拿「授权给我的工作站」再连。登录认证由网关向 AD 做，本机不认证、不存口令。
- **受管客户端不连非受管的机器**：要不到票就报原因、结束连接，不退回 RustDesk 的口令流程。
- **桌面端照网易 UU 远程的布局和样式改**（用户给了截图，「不用完全参照」）：主窗口是「我的设备」首页；远程窗口一台机器一个窗口、
  标题栏放屏幕标签和「控制中心」，全屏时用悬浮球。新写我们自己的界面，RustDesk 原来的首页、工具栏代码留着不维护，按产品版切换。
  起初把 kiosk 那套界面搬进桌面主窗口，用户否了（原有设置、菜单都没了），已撤回。
- **设置简化**：取消按机器存的设置，连接窗口里的设置项拿掉、只在设置页改；控制中心里的调整只管本次连接、不存盘；
  光标四项不留；鼠标模式（本地 / 远程）做成正式设置，专业模式也要支持相对模式；不做快捷键设置。菜单 / 设置的完整方案另定。
- **Windows 域账号自动登录**：加入域的电脑把当前域账号的登录凭据（AD 签发）交给网关核对；不成退回账号口令。
- **应急票撤掉**；**来历不明的连接**（网关查不到自己给这台签过的票）自动断开。
- **ID 机制保留，只当内部管道**（找地址、核对对方身份让连接加密、打洞和中继），用户看不到设备号。
  能不能连由网关的票决定，票里带着工作站的真实公钥、交票前核对，ID 服务器不是信任的根。
- **专业模式只在内网（含 VPN）用**。外网经中继只有通用模式，不做专业画面的中继。外网访问首选 VPN。

## 实施记录

### 第 1 步：必须登录（10-26，客户端）

- 受管时 `handle_hash` 不再走 RustDesk 的试口令：一律经 `managed_client::login_with_ticket`，要到票就交票登录，否则提示原因、结束连接。
- 主控端不再有「座位身份要票」：没登录的不发请求。设备签名的路径表去掉要票和问绑定两条，签名函数不再看请求带没带登录令牌。
- 票格式的主体只剩「用户」：2（座位）、3（应急）作废、不再复用，被控端收到按格式错误拒（和网关的验票用例一致）。

### 第 2 步：关掉入口（10-26）

- 用 RustDesk 给定制客户端的强制设置 / 内置设置（`brand::managed_lock`）：强制关「按 IP 直连」「局域网发现」，内置「不能改设备号」
  「不显示服务器设置」；正式版连 ID / 中继服务器、服务器公钥、网关地址也强制成内网的（10-21 放开的「ID 服务器可改」在受管版收回），
  开发版不锁地址，好用 `--option` 指到 0.208:8443 的联调网关。
- 局域网发现：RustDesk 的监听端口（UDP 21119）始终绑着，开关关了就不回应扫描，不是不绑端口。
- 实测（209.32、本机）：两项读出来都是 N；209.32 不再监听直连端口（之前日志里有直连）；向 21119 发局域网发现 ping，209.32 不回，
  对照机 59.82（不受管旧版）回了设备号、Windows 用户名和主机名；`--set-id` 报 Changing ID is disabled。
  正式版锁地址那一支要等产品钥填好才编得出来，没实际编过。

### 第 3 步：主窗口（10-26）

- 受管版（Rust 经 `main_get_common_sync("dd-managed")` 告诉界面）主窗口首页换成 `dd_home_page.dart`，kiosk 照旧，不受管的开发版
  照旧是 RustDesk 原首页。RustDesk 原首页照样建起来、只是不显示（远程窗口、设置页要它登记的东西）。
- 布局照 UU：浅灰标题栏和左栏连成一片，内容区更浅、左上角圆角；左栏「我的设备」列出授权工作站（`/api/dd/workstations`，在线点、
  系统小方块图标）和「全部设备」，左下角「设置」（就是 RustDesk 的设置页）；右边没登录是插画 +「立即登录」，登录后是全部设备卡片，
  或一台的详情（状态胶囊 + 名字、「进入桌面」大卡片、文件传输 / 终端 / 端口映射）。标题栏右边头像（点开小卡片：没登录是
  「立即登录」，登录了是名字和「退出登录」）、「更多」（关于、检查更新）、最小化 / 关闭。
- 登录框照 UU 另画，只有域账号口令，交给网关 `/api/login`；成功后照 RustDesk 原登录框存令牌和用户信息。
- 图标用一套 1.5 像素描边的细线图标（`dd_icons.dart`，图形照 Lucide，ISC 许可），Flutter 自带的 Material 图标线条改不细。
  横线类图标要落在整像素上，否则被平均成两行灰、看着粗。
- 手感：不用 `onDoubleTap`（它让单击等约 300 毫秒才生效、在标题栏上还和拖动抢鼠标），单击马上生效、自己按系统双击间隔判断双击，
  照 RustDesk 标签栏的做法；去掉点击水波纹；补上拖窗口边缘缩放（`DragToResizeArea`，和 RustDesk 原首页一样）。
- 「检查更新」：还没有升级分发，先如实告诉用户当前版本、新版本由 IT 安装；大卡片是画的风景，不是远程桌面的壁纸。

### 第 3b 步：远程窗口（10-26，A 部分）

- 分四小步：A 一台一个窗口 + 新标题栏 + 去悬浮工具栏 + 质量监测挪右下角；B 控制中心菜单按定稿补全；C 屏幕标签拖出成单独窗口；
  D 全屏悬浮球。
- 一台机器一个窗口：受管版不理「新连接开在标签里」（`multi_window_manager.dart` 一处），同一台再连照旧跳到已有窗口。
- 标题栏（`dd_remote_title_bar.dart`，40 像素）：机器名 + 连接安全标识｜每块远程屏一个标签（点了 `openMonitorInTheSameTab`，同一条连接）｜
  信号格（占位）+ 连接时长（第一次拿到对端信息起算）｜麦克风（RustDesk 语音通话）｜「控制中心」｜窗口按钮（RustDesk 原那组，关窗走原流程）。
  RustDesk 的标签组件 `DesktopTab` 加了可选的 `customBar`，受管版整条换掉；关窗、最大化、记位置照旧由它管。
- 标题栏比原来的 28 像素高：画面位置计算用的 `stateGlobal.tabBarHeight` 和「窗口贴合画面」改用 `kDdTabBarHeight`，不然鼠标差 12 像素。
- 控制中心：一级菜单照 UU；每项调 RustDesk 原工具栏背后的同一个功能（按菜单项的动作编号挑，确认框照原样），点开时才生成。
  调整现在还是 RustDesk 原样按机器存，「不存盘」随设置方案改。
- 悬浮工具栏：受管版不全屏时不画；全屏（标题栏收起）和 kiosk 在悬浮球做好之前仍用它。质量监测放右下角。

### 第 3b 步 D：全屏悬浮球（10-26）

- 受管版全屏和 kiosk 不再用 RustDesk 的悬浮工具栏，换成悬浮球（`dd_floating_ball.dart`）。外观和手感照专业窗口的球
  （`src/ddpro/ball.rs`）：42 像素圆角方块、浅灰底浅灰边，悬停白底蓝边；默认缩在顶边离右边 220 像素，缩进时整块藏起来，鼠标靠近
  那段边就滑出来；能拖，松手离边近就贴边，停在中间 1 秒回顶边。点开是控制中心那份菜单（`ddControlMenu`，标题栏和球共用），
  「全屏」换成「退出全屏」，kiosk 不给这一项。
- 踩过的坑：画球时问 `MenuController.isOpen`，第一次画时菜单还没挂上就抛错，发布版把铺满画面的那层画成灰色出错块，全屏画面
  整片灰白、点不动。改成用 MenuAnchor 的 onOpen / onClose 自己记；位置计算的 clamp 在窗口还没量好尺寸时也会抛错，一并防住。
- kiosk 换成悬浮球还没在瘦客户机上看过，等下次装 kiosk 包。

### 第 3b 步 C：屏幕标签拖出（10-26）

- 屏幕标签往下拖出标题栏（超过 24 像素松手）或右键「在新的窗口中打开」：用 RustDesk 原有的「在新窗口打开某块屏」
  （`openMonitorInNewTabOrWindow`，受管版一台一个窗口，所以总是新窗口），新窗口是单独一条连接。拖出的正是当前看的那块屏时，
  原窗口先切到下一块，免得两个窗口看同一块。只有一块屏时不能拖。
- 屏幕编号：`translate` 的占位符要写成 `Screen {2}`（编号写在括号里），之前写 `Screen {}` 再替换，编号被替成空，标签只显示「显示屏」。
- 实测（本机连 209.32，两块屏）：拖第 2 块、右键第 1 块（当前屏）各一次，新窗口和原窗口各显示对的那块屏。新窗口和原窗口叠在
  同一位置（RustDesk 原样）。
