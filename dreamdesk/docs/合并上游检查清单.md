# 合并上游检查清单

每月合并上游 RustDesk 后，按这份清单过一遍。**不是每处改动都列在这里**：被 `if (kDdManaged)` 包住的薄钩子上游改了会直接冲突，
冲突本身就是提醒；这里只列「编译不报错、冲突也不报，但上游改了我们这边会悄悄过时」的地方。
追加时用 Edit 在对应小节末尾加，别整文件重写（几个会话都在往里加）。

## 1. 受管版里拷贝了上游逻辑的地方（上游改了这里要同步）

| 我们的位置 | 拷贝自 | 同步什么 |
|---|---|---|
| `flutter/lib/desktop/widgets/dd_cm_view.dart` 的 `_items`（「允许对方」那排权限按钮） | `flutter/lib/desktop/pages/server_page.dart` 的 `_PrivilegeBoard` | 上游增删权限项、改权限名 / 条件（如 `isWindows`、隐私模式）时，这里照改 |
| `dd_cm_view.dart` 的 `ddCmButton`（按颜色字面量认按钮角色） | `server_page.dart` 的 `buildButton` 传来的 `color` | 上游改了接受 / 断开 / 语音通话几个按钮的颜色，这里的归类要跟着改 |
| `flutter/lib/desktop/widgets/dd_remote_dialogs.dart` 的 `ddCustomImageQualityWidget`（自定义画质：取值范围、去抖、回调） | `flutter/lib/common/widgets/setting_widgets.dart` 的 `customImageQualityWidget` | 上游改了取值范围 / 默认值 / 去抖 / 「更多」码率上限逻辑，这里照改 |
| `flutter/lib/desktop/widgets/dd_settings_restyle.dart` 的 `_unlock`（设置页的「解锁」，**安全相关**） | `flutter/lib/desktop/pages/desktop_setting_page.dart` 的 `_lock` 的 `onPressed` | 上游改了解锁流程（验证方式、PIN、提权检查）这里照改 |
| `dd_restyle.dart` 的 `ddComboBox`（选中逻辑） | `flutter/lib/common.dart` 的 `ComboBox` | 上游改了选中 / 取值逻辑这里照改 |
| `dd_settings_restyle.dart` 的 `ddSettingsTabItem`（点分类时切页） | `desktop_setting_page.dart` 的 `_listItem` 的 `onTap` | 上游改了切换分类的方式（`tabKeys`、`jumpToPage`）这里照改 |
| `flutter/lib/desktop/pages/server_page.dart` 里 `_CmHeader` 的受管钩子（`onChat`：什么时候给聊天按钮、点了开文件页还是聊天页） | 同文件 `_CmHeader` 原来的聊天按钮 | 上游改了聊天按钮的出现条件或动作，钩子里这段照改 |
| `server_page.dart` 里 `_PrivilegeBoard` 的受管钩子（`onToggle`：`checkClickTime` + `cmSwitchPermission`） | 同文件 `_PrivilegeBoard` 原来权限按钮的 `onTap` | 上游改了切权限的调用方式，钩子里照改 |
| `flutter/lib/desktop/pages/port_forward_page.dart` 里的受管钩子（`onAdd` / `onRemove`：增删转发的 bind 调用 + `refreshTunnelConfig`） | 同文件原来的添加 / 删除按钮 | 上游改了增删转发的调用或刷新方式，钩子里照改 |
| `flutter/lib/desktop/pages/file_manager_page.dart` 传输列表的受管钩子（删除任务：`jobTable.removeAt` + `cancelJob`） | 同文件 `statusList` 原来删除按钮的 `onPressed` | 上游改了删除 / 取消任务的做法，钩子里照改 |
| `flutter/lib/desktop/widgets/dd_remote_dialogs.dart` 的 `ddShowToast` | `flutter/lib/common.dart` 的 `showToast`（只换了样子） | 上游改了轻提示的挂法、去掉时机，这里照改 |

上面这些都是按「不改写上游、只加薄钩子」的规则有意拷贝的取舍：改上游那处代码会让非受管路径变形，不如拷一份换皮、合并时对一下。

## 2. 第三方插件 `dreamdesk/third_party/desktop_multi_window`

照该目录 `DREAMDESK.md` 的「合并上游时」一节做：上游 `flutter/pubspec.yaml` 里 `desktop_multi_window` 的 `ref` 变了，要换插件源码并补回我们加的
`setMinimumSize`（Dart / Windows / Linux 三端，改动处都带 `DreamDesk` 注释，搜它就能找全），再改 `DREAMDESK.md` 里的提交号。
本目录不要提交 `.dart_tool/`（`pub get` 生成，含本机绝对路径；已在该目录 `.gitignore` 里）。

## 3. 其它每次都要做的

- **重新生成 FFI 桥接**：改了 `src/flutter_ffi.rs` 或合并上游带来它的改动后，按仓库根 `CLAUDE.md`「构建」一节跑 `flutter_rust_bridge_codegen`（锁定 1.80.1）。
- **同步 `AGENTS-中文.md`**：`git log -1 --format=%h -- AGENTS.md`，原文变了就更新译本开头记的提交号和内容。
- **语言文件**：我们新增的词条只在 `src/lang/cn.rs`（英文即键，不动 `template.rs` 和其它语言文件）；合并后 grep 一下有没有键和上游新加的重复（重复键后者覆盖前者）。
- **通用模式审查**：`通用模式审查.md` 要求「每次合并上游、大改之后重跑一遍」。
- **「使用被控端鼠标」画被控端指针（`src/ddpro/cursor.rs`）依赖的上游几处**：`input_service.rs` 的 `run_pos`（两行钩子）和 `RELATIVE_MOUSE_CONNS`（列相对鼠标连接的函数）、`CursorPosition` 的 `dd_hidden` 字段；
  Dart 侧：`remote_page.dart` 画 `CursorPaint` 的条件和 `CursorPaint.build` 开头、`model.dart` 的 `CursorModel.updateCursorPosition` / `ddHidden`、`input_model.dart` 里 `ever(relativeMouseMode, …)` 的清状态、
  `relative_mouse_model.dart` / `remote_tab_page.dart` 的退出提示。上游若改了相对鼠标模式或远程光标的画法，这几处要对一遍。
