# 受管版菜单 / 设置方案（定稿，10-26）

参考网易 UU 远程，用户 10-26 定。

## 原则

- 远程相关的设置在每台机器的「控制中心」里调，按机器记住，用 RustDesk 原来的按机器存储。
- 设置页只放和远程无关的全局项。
- 动作类（切屏、Ctrl+Alt+Del、文件传输等）点了就执行，不涉及存不存。
- **设置项一律先保留、不删**，取舍以后再定。控制中心可以先不放某些项，但不从 RustDesk 里删。
- 不做快捷键设置，切屏、全屏也不配快捷键。
- 光标四项不放进控制中心。用户说先不删，所以设置页里有的照旧留着。

## 鼠标模式按机器记（唯一新加的存储）

**现状**：RustDesk 的相对鼠标模式不存盘。以下几种情况会自动关掉，防止鼠标被锁死在窗口里：
- 出错；
- 重连；
- 键盘权限被收回。

另外按 Ctrl+Alt 可以临时退出。

**做法**：
- 加一个按机器的选项，记住用户在菜单里选的本地或远程。
- 每次连上（包括重连），如果对方版本支持、而且有键盘权限，就按记住的值打开。
- 自动关闭和 Ctrl+Alt 临时退出都不改记住的值，只有在菜单里切换才改。
- 对方版本不支持时，这一项灰掉并说明原因。
- Ctrl+Alt 退出是逃生口，必须保留，不算快捷键设置。

**专业模式的相对鼠标**：后续新功能，和通用模式共用这一个记住的值，最后做。

## 设置页

- 所有页都先保留，包括安全、网络、打印机三页，都不藏。
- 「显示」页（新机器的初始值）已经置灰，加了「将移除」提示。以后再真删，真删时：
  - 新机器的初始值由产品固定一份：RustDesk 原默认，帧率改成 60，其余不变。
  - 不再读这一页以前留下的值。
  - 已经连过的机器有自己记住的值，不受影响。
  - 置灰期间照原样读这一页，作对照用。

## 先不做

- 旧版的 4:2:0、30 帧、精确模式：专业模式先不补。
- 控制中心先不放的项，都保留在 RustDesk 里、不删：
  - 只看不控、隐私模式；
  - 每屏独立窗口、用上我所有的屏；
  - 收起工具栏、交换 Ctrl/Command、触控板速度、键盘模式；
  - 光标四项。

## 依据（都已在代码里查过）

- 反转滚轮：存在按机器的配置里。
- 交换左右键：是按机器的开关项。
- 相对鼠标模式：不存盘，有上面那几处自动关闭。
- 窗口位置：按机器存，没有记录就退回全局位置。
- 分辨率：按机器、按屏存。
