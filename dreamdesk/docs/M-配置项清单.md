# RustDesk 配置项清单（受管版，10-27 整理）

用途：列出 RustDesk 的全部**全局设置**（设置页）和**每台机器的设置**（远程窗口工具栏），标出重复的，作为原型（`dreamdesk/design/prototype/`）
取舍的依据。「建议」一栏是我的建议，留不留由用户定；定了再改原型，原型定了再改代码。代码里一律先不删（见 M-菜单设置方案.md 的原则）。

## 先说清楚三件事

- **全局设置分三种存法**：本机的界面选项、本机的主配置（被控服务读的就是它）、「新机器默认值」。前两种改了立刻对所有连接生效。
- **「新机器默认值」只用一次**：每台机器第一次连时，从默认值抄一份存进这台的配置文件，以后各管各的。
  所以设置页「显示」那一页（全是默认值）改了，对已经连过的机器**没有用**——这是它和工具栏重复、又容易让人困惑的原因。
- **两侧要分开看**：设置页里一大半管的是「别人连我时允许做什么」（被控侧），工具栏管的是「我连别人时怎么看、怎么用」（主控侧）。
  名字像的不一定重复，见第三节。

受管版现状：「显示」页已整页置灰（将移除）；更换设备号、服务器设置已隐藏；按 IP 直连、局域网发现、IPv6、WebRTC 已锁死。

## 三、重复项

### 1. 真重复：设置页「显示」页的默认值 ↔ 控制中心里的同一项

显示方式、滚动方式（含贴边宽度）、画质（含自定义码率 / 帧率）、编码、触控板速度、查看模式、光标四项、质量监测、静音、允许复制粘贴文件、
禁用剪贴板、会话结束后锁定、隐私模式、真彩 4:4:4、反转滚轮、交换左右键、各屏单独窗口、将我的所有显示器、折叠工具栏、断开后保留终端会话。

这些在设置页里只是「新机器的初始值」，只在第一次连某台机器时用一次。去掉「显示」页后，新机器初始值由产品固定一份
（M-菜单设置方案：RustDesk 原默认，帧率改 60）。

### 2. 看着像、其实不重复（只有全局、没有按机器的）

- 「显示多屏菜单」、「主工具栏显示切屏按钮」、「工具栏停靠任意边」：只管 RustDesk 悬浮工具栏的样子，受管版没有悬浮工具栏，一起去掉。
- 「允许终端程序写剪贴板」：全局选项，不分机器。
- 「音频输入设备」（被控端采集哪个声卡）和语音通话里选的输入设备：各存各的，不是同一个值。

## 待定（要用户定）

- IP 白名单、设备白名单：网关已经管「谁能连哪台」，要不要留作被控端的最后一道。
- 键盘模式：出键位问题时要能切，放不放进控制中心。
- 隐私模式、虚拟显示器：控制中心给不给入口。
- 自动录制传入会话：公司有没有录像要求（有的话应由 IT 统一开，不让用户关）。
- 标「排查用」的技术项（渲染方式、打洞、WebSocket、TLS、UDP）：是留在设置页，还是收进一个「高级」折叠区。
