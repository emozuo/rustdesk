# 通用模式审查（对 RustDesk 原有文件的改动）

目的：不开 DreamDesk 的开关（`dd-pro` / `dd-brand` / `dd-managed`）编出来的程序，行为和原版 RustDesk 一致。
所以每处对原有文件的改动，要么被开关包住、关掉时原代码原样保留，要么关掉时和原版等价。**每次合并上游、大改之后重跑一遍。**

## 怎么跑

```sh
B=$(git merge-base dreamdesk upstream/master)
git diff --numstat $B dreamdesk -- . ':!dreamdesk' ':!src/ddpro' ':!src/lang'   # 改了哪些原有文件
git diff -U3 $B dreamdesk -- <文件>                                               # 逐个看
```

先看「改了原有行」的（numstat 第二列不为 0），再看纯新增里有没有不在开关下的。查完两种都编一遍：
Windows `cargo check --lib --features flutter,hwcodec,vram`（不开）和加上 `dd-pro,dd-brand,dd-managed`（开）；
Linux 在 WSL 编译副本里同样两遍（只在 Linux 编的代码，Windows 上查不到）。

## 2026-10-23 夜（基点 4e93a41ec）

33 个原有文件，+966 / −12。查出 3 处没被开关包住、通用模式行为变了，都是我们修的 RustDesk 原有毛病，已改成 `dd-pro` 下才生效、
不开时保留原来那一行：

| 位置 | 改了什么 | 来源 |
|---|---|---|
| `src/ipc.rs` `start_pa` | Linux 录音流给缓冲参数（每次 10 ms），原来 PipeWire 一次交几百毫秒、对端声音一阵一阵 | aa41e21ec |
| `src/platform/linux.rs` `get_default_pa_source` | 默认麦克风按 server_info 的 default_source 找；原来调的 pulsectl 函数拿扬声器名去音源里找，永远失败、退回采扬声器 | 4acfb82cc；**10-25 删掉**：上游合并进来的 pulsectl 新版（#16685）自己修了，同一个查法，改回原版那一行 |
| `src/server/connection.rs` 切换方向 | 按设备号找不到授权时按 UUID 找（按 IP 连接时授权登记在 IP 下，对方却按设备号回来） | 977d3b5ac |

这三处也是给上游提 PR 的候选（都是原版的毛病）。

关掉开关时和原版等价、不用改的：`libs/scrap/src/dxgi/mod.rs` 新字段默认关；`libs/portable/src/main.rs` 进程名常量不开 `dd-brand`
时就是原字符串；`src/platform/windows.rs` 安装脚本里多出的一行不开时是空行；`handle_voice_call` 拆开的判断不开时等价；
几处 `pub(crate)` 只改可见性；Flutter 的专业模式提示只在收到专业模式事件时显示，平时是不占位置的隐藏部件。

**有意的差异**（产品版要的，都在 `dd-brand` / `dd-pro` 下）：产品名和内网服务器、不探测公网 STUN；强制关「新连接在标签页中打开」；
默认开「将我的所有显示器用于远程会话」；受管模式（`dd-managed`）下的连接授权、设备签名、证书固定、克隆自查。

## 2026-10-26 夜（只看 10-23 审查之后我们自己的提交，c7aa4026f..）

这两天改原有文件的主要是受管版界面（主窗口、远程窗口标题栏、悬浮球、主题、设置页「显示」置灰）、kiosk、座位、必须登录。
查出 2 处不开开关时和原版不一样，已修：

| 位置 | 问题 | 修法 |
|---|---|---|
| 程序图标 `flutter/assets/icon.png`、`icon.ico`、`flutter/windows/runner/resources/app_icon.ico` | 10-26 换图标时直接改了仓库里的文件（前两个原版没有，是 RustDesk 给定制客户端的入口，有就用），不开开关编的程序也成了 DreamDesk 图标 | 图标只放 `dreamdesk/res/`（`icon-256.png`、`icon.ico`），仓库里那几处还原成上游；`build-windows.ps1`、`build-linux.sh` 编之前放进去、打完还原（要在 flutter build 之前放，不然不进资源清单、界面取不到） |
| `flutter/lib/utils/dd_kiosk.dart` `kDdKiosk` | 只看启动参数 `--kiosk`，Rust 那边没有这个角色、参数原样交给界面，不开开关的程序带它启动也换成 kiosk 页面 | 另要求 `kDdManaged`（产品只有受管版） |

其余都在开关下：Flutter 原有文件的改动都包在 `kDdManaged` / `kDdKiosk` 里，`kDdTabBarHeight` 不受管时就是原来的
`kDesktopRemoteTabBarHeight`；Rust 原有文件的改动都在 `dd-managed` / `dd-brand` 的 `cfg` 下（托盘图标、`dd-managed` 选项、
必须登录、座位不监听、座位上报）。`pubspec.yaml` 多登记的 kiosk 字体两种构建都会打进去（几百 KB），不影响行为。
