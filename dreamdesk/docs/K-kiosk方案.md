# kiosk 版方案（K 系列，2026-10-25）

## 目标

瘦客户机开机直接进入它绑定的那台工作站的专业模式全屏画面，用户看不到 Ubuntu 桌面、碰不到系统；断了自动接回去。
「先绑定、后登录」（10-23 已定）：K1 只做座位绑定一台工作站，按人登录选机器放 K2。

## 用户已定（10-25）

- 装在全新的 Ubuntu 26.04 上：IT 装好系统，再装我们的 kiosk 安装包，包把其余的都配好。不做整机镜像。
- 本机不提供维护入口：维护走远程 SSH，或者重装。
- 用户能主动断开：断开后回状态页，有「重新连接」「关机」。

## 已经具备的

- 服务端：座位登记、管理员确认、绑定工作站、座位凭设备签名要票（真机联调通过）；座位要票的状态码分清了「不是座位」和「座位被拒」。
- 客户端：专业模式（全屏、多屏、HDR、悬浮球、USB 透传、麦克风）、受管连接票、应急票、座位要票。
- 系统：Ubuntu 26.04 + GNOME 50，系统仓库自带 GNOME Kiosk 50.0（和 GNOME 50 同一个 mutter）。

## 组成

1. **系统外壳：GNOME Kiosk**
   - 专用账户 `kiosk`，开机自动登录进 kiosk 会话，会话里只跑我们的程序，程序退出或崩溃自动拉起。
   - 没有桌面、任务栏、终端、文件管理器；切虚拟终端、切窗口等系统快捷键关掉；屏保、锁屏、自动更新弹窗、蓝牙配对弹窗关掉。
   - 选它的理由：和现在的 GNOME 50 共用 mutter，HDR 开关（显示配置 D-Bus 接口）、显示器排布、专业窗口的零拷贝显示都由 mutter 提供，
     已经验证过的东西可以沿用。cage 等更小的合成器，这些都要重新做、重新验证。
2. **开机流程**（新的程序角色 `--kiosk`，kiosk 会话只起它）
   - 启动后凭设备签名问服务端「我绑定哪台」，以座位身份要票，用专业模式全屏连上。
   - 连不上时显示全屏状态页：一句话原因（服务器连不上 / 工作站离线 / 座位还没确认或没绑定 / 服务端给的拒绝原因）、
     自动重试倒计时、「重新连接」「关机」两个按钮，不显示别的。会话断了自动重连。
3. **悬浮球**：保留现有功能，加「断开（回状态页）」和「关机 / 重启」。其余设置全部内置，不给用户改。
4. **安装包** `dreamdesk-kiosk`（依赖 `dreamdesk-pro`、`gnome-kiosk`、`openssh-server`）：装上后建 `kiosk` 账户，配好自动登录和
   kiosk 会话，关掉不需要的系统组件；卸载时还原。远程维护用 IT 自己的管理员账户 SSH 进来。
5. **安全**
   - `kiosk` 账户没有 sudo、没有终端，程序和系统配置都读写不了。
   - 座位密钥被偷了的后果：能从别处使用这个座位绑定的那台工作站。坐在座位前本来就能用，所以风险不大。
     服务端已经有「同一把公钥从两处报到 → 判为疑似克隆 → 停发票」；再加一条「座位从登记之外的地址要票就告警」。
     磁盘加密做成可选项。
   - 被控端仍然只认连接票，kiosk 这边不存任何口令。
6. **升级**：K1 手动装新包；内网 apt 源自动升级放 K3。

## K1 拆成几步（每步都有机器判据）

| # | 内容 | 机器判据 |
|---|---|---|
| 1 | 座位问绑定：GET `/api/dd/seat/target` 带设备签名（签名现在只挂在 POST 上，要补 GET） | 联调包上问到绑定的那台；没绑定 / 没确认分别拿到对应的原因 |
| 2 | `--kiosk` 角色：问绑定 → 要票 → 专业模式连上；失败重试、断了重连（先不做界面，只做流程） | 瘦客户机上起 `--kiosk`：连上；停服务端 / 关工作站 / 断网后自动恢复，日志可数 |
| 3 | 安装包：建账户、自动登录、kiosk 会话、关系统组件、卸载还原 | 装包和卸包前后系统状态逐项对比；重启后 kiosk 会话里只有我们的进程 |
| 4 | 状态页、悬浮球的「断开」「关机」 | 界面要人看；按钮背后的动作（断开、关机）用命令触发验证 |
| 5 | 锁定：快捷键、屏保、弹窗 | 注入按键看有没有切走；等过屏保时间看有没有锁屏 |
| 6 | 服务端：座位换地址要票告警 | 换个源地址要票，看告警和计数 |

## 实施记录

### 断开、掉线、重试各归谁（10-25）

- **问绑定**归 kiosk 页：问不到（服务器连不上、座位没确认 / 没绑定 / 被拒）显示服务端给的原因，按 5、10、20、30、60 秒退避再问。
- **连上之后**归远程窗口：掉线、工作站离线、要票失败都在远程窗口里自动重试。RustDesk 自己对「离线」「失败」这类错误不重试、
  重试间隔每次翻倍不封顶；kiosk 进程里改成凡是报错都重试、间隔最长 60 秒（Dart 侧两处一行钩子）。
  服务端连不上时平常弹口令框等粘贴应急票，kiosk 前没人能粘贴，改成报错重试。
- **远程窗口只在用户断开时关**：专业画面里掉线时专业窗口退出、露出通用窗口里 RustDesk 的重连提示，远程窗口不关；
  关窗口只有悬浮球「断开」和提示框里点取消。所以 kiosk 页看到远程窗口关了，就当成用户断开：回状态页、不自动再连。
- 「是不是 kiosk」读本进程启动参数（`/proc/self/cmdline`）：远程窗口和主窗口在同一个进程、但各自一个 Dart 环境，
  主窗口设的全局变量远程窗口看不到。
- kiosk 页之下照样建原来的主窗口页（不显示）：远程窗口要主窗口应答一套请求（屏幕列表、窗口激活登记等），
  那套应答写在原来的首页里。只换掉首页时远程窗口一开就报「没有这个方法」。

### 安装包（10-25）

- 装法：`apt-get install --no-install-recommends ./dreamdesk-pro-*.deb ./dreamdesk-kiosk-*.deb`。不加 `--no-install-recommends` 时
  apt 会顺带装上 gnome-kiosk 推荐的两个示例会话（搜索机、脚本会话），开机自动登录用不到，但多两个会话入口。
- 会话照 gnome-kiosk-script-session 的结构：wayland 会话文件 → gnome-session 会话 → 用户级 systemd 目标要求 GNOME Kiosk 和
  我们的程序；我们的程序退出或崩溃 2 秒后拉起，不结束会话（官方示例退出就回登录界面）。
- 装包：建 `kiosk` 账户（口令锁住、只能自动登录）、默认会话设成 DreamDesk Kiosk、GDM 自动登录改成它；改 GDM 前留原样。
  已有一个不是本包建的 `kiosk` 账户时停下不装，不动别人的账户。卸载还原 GDM 设置；彻底删除（purge）连账户一起删。
- 开机被登录界面盖住（瘦客户机实测，10-25）：非 GNOME 桌面的会话由 GDM 的会话包装程序代报「画面就绪」，要等 10 秒；
  GDM 在会话报到时也起了个 10 秒计时器，到点没收到就硬关开机动画，前台落回 1 号终端，GDM 在那里另起登录界面、成了前台，
  kiosk 会话被挤到后台（官方 gnome-kiosk-script 会话同样如此）。修法：我们的程序一起来就自己向 GDM 报「画面就绪」
  （系统总线 `RegisterDisplay`，不带参数），和 GNOME 桌面由 gnome-shell 自己报是同一条路。

### 锁定（K1 第 5 步，10-25）

只作用于 kiosk 账户 / kiosk 会话，其它账户照旧：
- **系统自动启动项一个不起**：GNOME 50 的会话管理没有关掉自动启动的开关，它只从 `XDG_CONFIG_DIRS` 下的 autostart 目录找；
  kiosk 会话的会话管理服务（`gnome-session-manager@dreamdesk-kiosk.service`）加一份补丁把它指向本包自带的空目录。
  逐条屏蔽会被以后新装的包绕过，这样不会。
- **挂在所有会话上的用户级单元**（首次登录向导、升级介绍、崩溃报告、升级提示、snap 刷新、使用统计、文件索引）：
  在 kiosk 账户下逐个屏蔽，清单在 `dreamdesk/kiosk/masked-user-units`。它们挂在 GNOME 共用的启动目标上，摘不掉，只能按名屏蔽；
  首次登录向导的「升级介绍」检查的标记带系统版本号，补标记文件下个版本就失效。
- **快捷键、锁屏**：装包时把本包的设置文件编进 kiosk 账户自己的设置库：关掉切终端（Ctrl+Alt+F1–F12）、
  恢复快捷键（Super+Esc）、锁屏、空闲计时。
- **电源键**：会话里不起 GNOME 的媒体键守护进程（它会接管电源键），电源键归系统，按 logind 默认关机。
- 检查：开机后前台是 kiosk 会话、没有登录界面；kiosk 账户下没有自动启动项；设置读出来是上面的值；没有程序接管电源键；
  注入 Ctrl+Alt+F3 / F1 不切走（同一个注入在普通桌面上会切走，证明注入本身有效）。

## 分期

- **K1**：上表。
- **K2**：按人登录、选机器（服务端已经能以用户身份发票）。
- **K3**：批量部署脚本、内网 apt 源自动升级。

## 要人看的

状态页和悬浮球的样子、全屏观感、HDR 和多屏在 kiosk 会话下的表现、开机过程有没有闪出系统界面。
